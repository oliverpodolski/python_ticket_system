This project is a Ticket System that can be used by the console.
I created this project to learn more about MySQL, OOP and backend logic.

Features:
- Create Users
- Login System
- Create Tickets
- Show User Tickets
- Change Ticket Status

How to run:
  1. install python
  2. install dependencies
       - pip install -r requirements.txt
  3. create a .env file
       Example:
         host=YOUR_HOST
         user=YOUR_USER
         password=YOUR_PASSWORD
4. Start the project
       - python main.py
